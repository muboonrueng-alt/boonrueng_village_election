# ระบบรายงานผลเลือกตั้งหมู่บ้าน (Next.js + Supabase)

คู่มือนี้เขียนแบบละเอียดที่สุด สำหรับคนที่ไม่เคยเขียนโปรแกรมมาก่อน
**ทำตามทีละขั้นตามลำดับ ห้ามข้าม** ไม่ต้องเข้าใจทุกบรรทัด ทำให้รันได้ก่อน แล้วค่อยๆ ทำความเข้าใจทีหลัง

ระบบมี 3 role:
1. **เจ้าหน้าที่ (staff)** — กรอกคะแนนของหมู่บ้าน พร้อมแนบรูปถ่าย
2. **แอดมิน (admin)** — แก้ไขคะแนนที่ล็อกแล้ว, แก้ชื่อต่างๆ, จัดการใบเลือกตั้ง/ผู้สมัคร
3. **ประชาชน (public)** — ดูแดชบอร์ดผลคะแนนแบบสด ไม่ต้อง login

---

## ขั้นตอนที่ 0 — เตรียมเครื่องมือ (ทำครั้งเดียว)

ติดตั้งโปรแกรมเหล่านี้ก่อน ทีละอย่าง (ถ้ามีอยู่แล้วข้ามได้):

1. **Node.js** (เวอร์ชัน 20 ขึ้นไป) — โหลดที่ https://nodejs.org (เลือกปุ่มสีเขียว LTS) ติดตั้งแบบกด Next ไปเรื่อยๆ ได้เลย
2. **VS Code** — โหลดที่ https://code.visualstudio.com (โปรแกรมไว้เปิด/แก้โค้ด) ติดตั้งแบบกด Next ไปเรื่อยๆ
3. **บัญชี Supabase** (ฟรี) — สมัครที่ https://supabase.com ใช้ email สมัครหรือ sign in ด้วย GitHub ก็ได้
4. **บัญชี GitHub** (ฟรี, ใช้ตอนท้ายๆ ตอน deploy) — สมัครที่ https://github.com
5. **บัญชี Vercel** (ฟรี, ใช้ตอนท้ายๆ ตอน deploy) — สมัครที่ https://vercel.com

### เช็คว่าติดตั้ง Node.js สำเร็จ

- **Windows:** กดปุ่ม Start พิมพ์ "cmd" กด Enter จะเปิดหน้าต่างดำๆ ขึ้นมา (เรียกว่า Command Prompt)
- **Mac:** เปิด Spotlight (กด `Cmd + Space`) พิมพ์ "Terminal" กด Enter

ในหน้าต่างดำที่เปิดขึ้นมา พิมพ์คำสั่งนี้แล้วกด Enter:
```
node -v
```
ถ้าขึ้นเลขเวอร์ชัน เช่น `v20.11.0` แปลว่าติดตั้งสำเร็จ ปิดหน้าต่างนี้ได้เลย ไปขั้นตอนถัดไป

## ขั้นตอนที่ 1 — เปิดไฟล์โปรเจกต์ที่ได้รับมา

คุณได้ไฟล์ชื่อ **`village-election-starter.zip`** มา (ดาวน์โหลดจากข้อความก่อนหน้านี้) นี่คือขั้นตอนเปิดมันตั้งแต่ต้น

### 1.1 แตกไฟล์ zip

**Windows:**
1. หาไฟล์ `village-election-starter.zip` ในโฟลเดอร์ Downloads
2. คลิกขวาที่ไฟล์ → เลือก **Extract All...** → กด **Extract**
3. จะได้โฟลเดอร์ชื่อ `village-election-starter` ขึ้นมา ข้างในมีโฟลเดอร์ย่อยอีกชั้นชื่อ `village-election`

**Mac:**
1. หาไฟล์ `village-election-starter.zip` ในโฟลเดอร์ Downloads
2. ดับเบิลคลิกที่ไฟล์ — macOS แตกไฟล์ให้อัตโนมัติ ได้โฟลเดอร์ `village-election-starter` ขึ้นมา

> จำตำแหน่งโฟลเดอร์นี้ไว้ เช่น `Downloads/village-election-starter/village-election`
> **โฟลเดอร์ที่จะใช้จริงคือ `village-election` (ชั้นใน)** ที่มีไฟล์ `package.json` อยู่ข้างใน ไม่ใช่โฟลเดอร์ชั้นนอก

### 1.2 เปิดโฟลเดอร์ด้วย VS Code

1. เปิดโปรแกรม **VS Code**
2. เมนูด้านบน กด **File → Open Folder...** (Mac: **File → Open...**)
3. เลือกโฟลเดอร์ `village-election` (ชั้นในที่มี `package.json`) → กด **Open** / **เลือกโฟลเดอร์**
4. ทางซ้ายของ VS Code ควรเห็นรายชื่อไฟล์/โฟลเดอร์ เช่น `app`, `lib`, `supabase`, `package.json`, `README.md` — ถ้าเห็นแบบนี้แปลว่าเปิดถูกที่แล้ว

### 1.3 เปิด Terminal ข้างใน VS Code

Terminal คือช่องพิมพ์คำสั่ง จะใช้พิมพ์คำสั่งทุกอย่างต่อจากนี้ทั้งหมด

1. เมนูด้านบนของ VS Code กด **Terminal → New Terminal**
   (ปุ่มลัด Windows: `` Ctrl + ` `` , Mac: `` Cmd + ` ``)
2. จะมีช่องเปิดขึ้นด้านล่างจอ มีเคอร์เซอร์กระพริบรออยู่
3. ทดสอบพิมพ์คำสั่งนี้แล้วกด Enter เพื่อเช็คว่าอยู่ถูกโฟลเดอร์:
   ```
   dir
   ```
   (Mac/Linux ใช้ `ls` แทน)

   ถ้าเห็นรายชื่อไฟล์ `package.json`, `README.md`, `app` ขึ้นมา แปลว่าอยู่ถูกที่ ไปต่อได้เลย

### 1.4 ติดตั้ง dependencies (โค้ดที่โปรเจกต์ต้องใช้)

ในช่อง Terminal เดิม พิมพ์คำสั่งนี้แล้วกด Enter:
```
npm install
```
- จะมีตัวหนังสือวิ่งเต็มจอ รอจนกว่ามันจะหยุดวิ่งและกลับมาที่เคอร์เซอร์รอพิมพ์ (ประมาณ 1-3 นาที)
- เสร็จแล้วจะมีโฟลเดอร์ใหม่ชื่อ `node_modules` โผล่ทางซ้าย (ไม่ต้องไปยุ่งกับมัน มันคือโค้ดของคนอื่นที่โปรเจกต์เรียกใช้)
- ถ้าขึ้น error สีแดง ลองพิมพ์ `node -v` เช็คว่าเวอร์ชัน Node.js ขึ้นมาจริงไหม ถ้าไม่ขึ้นให้กลับไปขั้นตอนที่ 0

ถึงตรงนี้ **โปรเจกต์ "เปิด" สำเร็จแล้ว** แต่ยังรันไม่ได้ เพราะยังไม่ได้ต่อกับฐานข้อมูล (Supabase) — ไปขั้นตอนที่ 2 ต่อ

## ขั้นตอนที่ 2 — สร้างฐานข้อมูลบน Supabase

### 2.1 สร้างโปรเจกต์ Supabase

1. เข้า https://supabase.com → login → กด **New project**
2. ตั้งชื่อโปรเจกต์ เช่น `village-election`
3. ตั้งรหัสผ่านฐานข้อมูล (**จดเก็บไว้ที่ไหนสักที่**) แล้วกด **Create new project**
4. รอประมาณ 1-2 นาทีให้ระบบสร้างเสร็จ (จะมีหน้า loading)

### 2.2 คัดลอกกุญแจเชื่อมต่อ (API Keys)

1. ในหน้าโปรเจกต์ (Supabase Dashboard) มองแถบซ้าย กดไอคอนเฟือง ⚙️ **Project Settings** → เมนู **API**
2. จะเห็นค่า 2 อย่าง คัดลอกเก็บไว้ในโน้ตหรือ Notepad ก่อน (จะใช้ในข้อ 2.5):
   - **Project URL** (หน้าตาแบบ `https://xxxxx.supabase.co`)
   - **anon public** key (สตริงยาวๆ ขึ้นต้นด้วย `eyJ...`)

### 2.3 สร้างตารางฐานข้อมูล (รัน SQL)

1. แถบซ้ายของ Supabase กดเมนู **SQL Editor** (ไอคอนหน้าจอเทอร์มินัล)
2. กดปุ่ม **New query**
3. กลับไปที่ VS Code เปิดไฟล์ `supabase/schema.sql` (อยู่ทางซ้าย โฟลเดอร์ `supabase`) กด `Ctrl+A` (Mac: `Cmd+A`) เพื่อเลือกทั้งหมด แล้ว `Ctrl+C` (Mac: `Cmd+C`) เพื่อคัดลอก
4. กลับไปหน้า Supabase SQL Editor คลิกในช่องว่าง แล้ว `Ctrl+V` (Mac: `Cmd+V`) วาง
5. กดปุ่ม **Run** (หรือ `Ctrl+Enter`) มุมขวาล่าง
6. ถ้าไม่มี error สีแดงขึ้นมา แปลว่าสำเร็จ — ลองไปเช็คที่แถบซ้าย เมนู **Table Editor** ควรเห็นตารางใหม่หลายตัว: `profiles`, `villages`, `ballots`, `candidates`, `submissions`, `ballot_stats`, `candidate_votes`, `settings`

### 2.4 สร้างที่เก็บรูปถ่าย (Storage)

1. แถบซ้าย กดเมนู **Storage**
2. กด **New bucket**
3. ตั้งชื่อ bucket ว่า `submission-photos` (พิมพ์ตามนี้เป๊ะๆ ตัวพิมพ์เล็กทั้งหมด)
4. เปิด toggle **Public bucket** ให้เป็นสีเขียว/เปิดใช้งาน
5. กด **Create bucket**

### 2.5 ใส่ค่าเชื่อมต่อลงไฟล์ .env.local

1. กลับไปที่ VS Code แถบไฟล์ทางซ้าย หาไฟล์ชื่อ `.env.local.example`
2. คลิกขวาที่ไฟล์ → **Copy** (คัดลอก)
3. คลิกขวาที่พื้นที่ว่างในรายการไฟล์ → **Paste** (วาง) จะได้ไฟล์ใหม่
4. คลิกขวาไฟล์ใหม่นั้น → **Rename** → เปลี่ยนชื่อเป็น `.env.local` ตรงๆ (ไม่มีคำว่า copy หรือ example ต่อท้าย)
5. ดับเบิลคลิกเปิดไฟล์ `.env.local` แล้วแก้ให้เป็นค่าที่คัดลอกมาจากข้อ 2.2:
   ```
   NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...ค่ายาวๆ-ที่คัดลอกมา
   ```
6. กด `Ctrl+S` (Mac: `Cmd+S`) บันทึกไฟล์

### 2.6 เปิดใช้ระบบ Login (Auth) + สร้างบัญชีทดสอบ

1. แถบซ้าย Supabase กดเมนู **Authentication** → **Providers** → เช็คว่า **Email** เปิดใช้งานอยู่ (ปกติเปิดอยู่แล้ว)
2. ไปที่ **Authentication** → **Users** → กด **Add user** → **Create new user**
   - สร้างคนแรก: email `staff@example.com` ตั้งรหัสผ่านเอง (จดไว้) → กด Create
   - สร้างคนที่สอง: email `admin@example.com` ตั้งรหัสผ่านเอง (จดไว้) → กด Create
3. คลิกที่ user แต่ละคนที่เพิ่งสร้าง คัดลอกค่า **User UID** ของแต่ละคนเก็บไว้ (หน้าตาเป็นรหัสยาวๆ)
4. ไปที่ **Table Editor** → เลือกตาราง `profiles` → กด **Insert** → **Insert row**
   - แถวของ staff: `id` = UID ของ staff ที่คัดลอกมา, `role` พิมพ์ `staff`, `full_name` ใส่ชื่อที่ต้องการ → Save
   - แถวของ admin: `id` = UID ของ admin, `role` พิมพ์ `admin`, `full_name` ใส่ชื่อที่ต้องการ → Save

## ขั้นตอนที่ 3 — รันโปรเจกต์บนเครื่องตัวเอง

1. กลับไปที่ VS Code ที่ช่อง Terminal (ถ้าปิดไปแล้วเปิดใหม่ตามข้อ 1.3)
2. พิมพ์คำสั่ง:
   ```
   npm run dev
   ```
3. รอสักครู่ จะเห็นข้อความประมาณ:
   ```
   ▲ Next.js 14.2.5
   - Local:  http://localhost:3000
   ```
4. เปิดเบราว์เซอร์ (Chrome/Edge) พิมพ์ที่แถบ URL ด้านบนว่า `http://localhost:3000` แล้วกด Enter
5. ควรเห็นหน้าเว็บแดชบอร์ดขึ้นมา (ตัวเลขจะยังเป็น 0 เพราะยังไม่มีข้อมูล ต้องทำขั้นตอนที่ 4 ก่อน)

หน้าอื่นๆ ที่มีในระบบ:
- หน้ากรอกคะแนน (เจ้าหน้าที่): `http://localhost:3000/staff`
- หน้าแอดมิน: `http://localhost:3000/admin`
- หน้า login: `http://localhost:3000/login`

> **หยุดรัน:** กลับไปที่ Terminal กด `Ctrl + C`
> **รันใหม่:** เปิด Terminal ในโฟลเดอร์นี้ (ข้อ 1.3) แล้วพิมพ์ `npm run dev` อีกครั้ง (ไม่ต้อง `npm install` ซ้ำ)

## ขั้นตอนที่ 4 — ใส่ข้อมูลตั้งต้น (หมู่บ้าน / ใบเลือกตั้ง / ผู้สมัคร)

ตอนรัน schema.sql ในขั้นตอนที่ 2.3 ระบบใส่ตัวอย่างหมู่บ้านกับใบเลือกตั้งให้แล้วบางส่วน แต่ **ผู้สมัคร (candidates) ยังไม่มี** ต้องเพิ่มเองผ่าน Supabase:

1. Supabase → **Table Editor** → เลือกตาราง `candidates` → กด **Insert row**
2. ใส่ข้อมูลทีละคน:
   - `ballot_id` — กดเลือกจาก dropdown (จะโยงกับใบเลือกตั้งในตาราง `ballots`)
   - `name` — ชื่อผู้สมัคร เช่น "สมชาย ใจดี"
   - `number` — เบอร์ผู้สมัคร (ถ้ามี)
   - `color` — รหัสสี เช่น `#B08D3E`
   - `order_no` — ลำดับ 1, 2, 3, ...
3. ทำซ้ำจนครบทุกคนในทุกใบเลือกตั้ง

(อยากแก้ไข/เพิ่มหมู่บ้านหรือใบเลือกตั้งเพิ่มเติม ก็ทำแบบเดียวกันในตาราง `villages` และ `ballots`)

## ขั้นตอนที่ 5 — ทดสอบการทำงานจริง

1. เข้า `http://localhost:3000/login` → ล็อกอินด้วย `staff@example.com`
2. ระบบพาไปหน้า `/staff` → เลือกหมู่บ้าน → กรอกคะแนนทุกใบเลือกตั้ง + ผู้มาใช้สิทธิ์ + บัตรเสีย + แนบรูป → กด "ยืนยันและบันทึก"
3. เปิดอีกแท็บเบราว์เซอร์ไปที่ `http://localhost:3000` (แดชบอร์ดสาธารณะ) — ตัวเลขควรไล่นับขึ้นให้เห็นสด โดยไม่ต้อง refresh หน้า
4. ล็อกอินด้วย `admin@example.com` เข้า `/admin` เพื่อดู/แก้ไขคะแนนที่เจ้าหน้าที่กรอกไป

---

## ขั้นตอนที่ 6 — เอาเว็บขึ้นออนไลน์ (Deploy ให้คนอื่นเข้าได้จริง)

1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub (สร้าง repo ใหม่ที่ https://github.com/new แล้ว push โค้ดขึ้นไป — ถ้าไม่เคยทำมาก่อน ค้นหา "github create repo push code" จะมีคำแนะนำในหน้า GitHub เอง หรือถามเพิ่มได้)
2. เข้า https://vercel.com → **Add New... → Project** → เลือก repo ที่เพิ่ง push ขึ้นไป
3. ตอนตั้งค่า ใส่ **Environment Variables** (ค่าเดียวกับใน `.env.local`):
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. กด **Deploy** รอสักครู่ จะได้ลิงก์เว็บจริง เช่น `https://your-project.vercel.app` ส่งลิงก์นี้ให้ใครก็เข้าดูได้

## โครงสร้างไฟล์สำคัญ

```
village-election/
├── supabase/schema.sql        ← โครงฐานข้อมูลทั้งหมด (รันใน SQL Editor ขั้นตอนที่ 2.3)
├── app/
│   ├── page.tsx                ← แดชบอร์ดสาธารณะ (ไม่ต้อง login)
│   ├── login/page.tsx          ← หน้า login
│   ├── staff/page.tsx          ← หน้ากรอกคะแนน (เจ้าหน้าที่)
│   └── admin/page.tsx          ← หน้าแก้ไขข้อมูล (แอดมิน)
├── lib/
│   ├── supabase/client.ts      ← ตัวเชื่อมต่อ Supabase ฝั่ง browser
│   ├── supabase/server.ts      ← ตัวเชื่อมต่อ Supabase ฝั่ง server
│   ├── hooks/useCountUp.ts     ← เอฟเฟกต์ตัวเลขนับขึ้นทีละ 1
│   └── types.ts                ← ชนิดข้อมูล TypeScript
└── middleware.ts               ← เช็ค role ก่อนเข้าหน้า /staff, /admin
```

## หมายเหตุสำคัญ

- โค้ดชุดนี้เป็น **จุดเริ่มต้นที่ใช้งานได้จริง** แต่ยังเป็นเวอร์ชันพื้นฐาน (MVP) — ยังไม่มีหน้าให้แอดมินเพิ่ม/ลบหมู่บ้าน-ใบเลือกตั้งผ่านเว็บ (ต้องทำผ่าน Table Editor ไปก่อนตามขั้นตอนที่ 4), ยังไม่มีการตรวจสอบข้อมูลในฟอร์มแบบละเอียด
- RLS (Row Level Security) ถูกตั้งไว้ในตารางแล้วตาม role เพื่อความปลอดภัยพื้นฐาน แต่ก่อนใช้งานจริงจริงจัง ควรให้คนที่ถนัดด้านความปลอดภัยตรวจสอบอีกรอบ
- ติดปัญหาตรงไหน ไม่รู้จะแก้ยังไง ลองคัดลอก error message ทั้งบรรทัด (สีแดงที่ขึ้นใน Terminal หรือในเบราว์เซอร์) มาถามได้เลย จะช่วยดูให้
